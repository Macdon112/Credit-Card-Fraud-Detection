# Datasage Consulting Limited - Professional Website

A modern, responsive website for Datasage Consulting Limited, showcasing strategic consulting, advanced analytics, and innovative solutions.

## 🚀 Quick Start

To run the website locally:

1. Open `index.html` in your web browser
2. Or use a simple HTTP server for the best experience:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```
3. Navigate to `http://localhost:8000` in your browser
